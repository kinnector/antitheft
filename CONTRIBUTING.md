# Contributing

Thanks for helping make antitheft better.

antitheft's source code is not public, so this repository takes no code. What helps most:

- **Bug reports.** What happened, what you expected, your system and antitheft version (the Updates button in the app's
  title bar). [Report a bug](https://github.com/kinnector/antitheft/issues/new?template=bug-report.yml).
- **False alerts.** antitheft stopped or flagged a program you trust. The alert's program, the app that started it and
  what it reached for tell us what to fix.
  [Report a false alert](https://github.com/kinnector/antitheft/issues/new?template=false-alert.yml).
- **Apps to protect.** A wallet, password manager, messenger or other app whose data antitheft should guard.
  [Request an app](https://github.com/kinnector/antitheft/issues/new?template=app-request.yml).
- **Documentation fixes.** Pull requests to the files in `docs/` and the README are welcome.

Before you post, remove anything private from logs and screenshots: your user name in paths if you like, email
addresses, wallet addresses, account names. Never post a seed phrase, password, token or private key, even an old one.

Security problems go to [SECURITY.md](SECURITY.md), not to issues.

By taking part you agree to the [Code of Conduct](CODE_OF_CONDUCT.md).

# Code of Conduct

Be kind, be patient and stay on topic. People come here because something on their computer worried them.

Not accepted: harassment, insults, personal attacks, discrimination of any kind, publishing anyone's private
information, spam and advertising, and posting malware, stolen data or links to them (a sample for a report goes to
[security@antitheft.pro](mailto:security@antitheft.pro), not here).

We may edit or remove posts and block accounts that break these rules. To report a problem with someone's
behaviour, write to [support@antitheft.pro](mailto:support@antitheft.pro).

This code is based on the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/).

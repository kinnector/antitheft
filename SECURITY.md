# Security

## Report a security problem

Found a security problem in antitheft? Report it privately, never in a public issue:

- through GitHub: **Security > Report a vulnerability** on this repository, or
- by email: [security@antitheft.pro](mailto:security@antitheft.pro)

Say what you found, how to reproduce it, which version of antitheft and which operating system you used, and how we
can reach you.

## What you may examine

You may examine antitheft in any way you like on computers you own or are allowed to test: decompile it, debug it,
analyse its network traffic, or have a tool or an AI model analyse it. You do not need to ask us first.

Please don't access, change or delete other people's accounts or data, disrupt our servers, publish a problem before we
had a reasonable time to look at it, or try to trick our team or our users.

The full policy, including our safe harbor for good-faith research: [antitheft.pro/security](https://antitheft.pro/security/).
We do not run a paid bounty.

## Supported versions

Only the latest release is supported. Installed copies update themselves (see [docs/updates.md](docs/updates.md)).

## Checking a release

Every release is signed with the antitheft release key. How to check one: [docs/verify.md](docs/verify.md).

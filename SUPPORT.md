# Getting help

- **How do I...?** Start with the [FAQ](docs/faq.md) and the [install guide](docs/install.md).
- **Account, subscription, payment or refund:** write to [support@antitheft.pro](mailto:support@antitheft.pro), or use
  Support in the app or in your [account](https://antitheft.pro/account/). Never post account details in a public issue.
- **Something doesn't work:** [report a bug](https://github.com/kinnector/antitheft/issues/new?template=bug-report.yml).
- **antitheft stopped something you trust:** [report a false alert](https://github.com/kinnector/antitheft/issues/new?template=false-alert.yml).
- **An app you want protected:** [request it](https://github.com/kinnector/antitheft/issues/new?template=app-request.yml).
- **A security problem:** see [SECURITY.md](SECURITY.md). Never in a public issue.
- **Business licence:** [business@antitheft.pro](mailto:business@antitheft.pro).
